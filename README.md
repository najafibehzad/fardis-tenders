# گزارش روزانه آگهی‌های فردیس (ستادیران)

هر روز **ساعت ۱۵:۰۰ به وقت ایران** (۱۱:۳۰ UTC) به‌صورت خودکار روی GitHub Actions:

1. آگهی‌های فعال تابلوی اعلانات مرکزی سامانه تدارکات الکترونیکی دولت با فیلتر **استان البرز / شهر فردیس** گرفته می‌شود.
2. مشخصات کامل مناقصات (از etend) و استعلام‌های خدمات/پیمانکاری (از eproc) استخراج می‌شود.
3. گزارش فارسی RTL (HTML + PDF) با قواعد ثابت ساخته می‌شود: جدیدترین در بالا، مهلت‌گذشته‌ها قرمز، ستون «زمان ارسال به صفحه اعلام» از تاریخچه پایش، لینک فعال هر اگهی به صفحه رسمی، نشان «جدید».
4. **مزایده‌ها و استعلام‌های خرید کالا حذف می‌شوند** (به درخواست صاحب گزارش).
5. گزارش و تاریخچه پایش (history.json) در همین ریپو commit و آخرین نسخه روی GitHub Pages منتشر می‌شود.

## مشاهده گزارش

- **نسخه وب (همیشه آخرین):** `https://<username>.github.io/fardis-tenders/`
- **PDF:** فایل `report.pdf` در ریشه ریپو (یا `/report.pdf` روی Pages)
- نتیجه هر اجرا: تب **Actions** → آخرین اجرا → خلاصه (Summary)

## اجرای دستی

از تب Actions → «گزارش روزانه فردیس» → **Run workflow**.

یا لوکال:

```bash
npm install
npx playwright install chromium   # یا متغیر CHROME_PATH به کروم نصب‌شده
node run_pipeline.mjs
```

## تغییر شهر یا ساعت

- شهر: آرگومان‌های `fetch_announcements.js` در `run_pipeline.mjs` (مثلاً «البرز» «کرج»).
- ساعت: cron در `.github/workflows/daily.yml` (بر حسب UTC؛ ایران = UTC+3:30 ثابت).

## نکته‌ها

- تاریخچه «زمان ارسال به صفحه اعلام» در `setadiran-data/البرز-فردیس/history.json` نگه‌داری می‌شود؛ پاک کردن آن، ستون زمان انتشار اگهی‌های قبلی را به «—» برمی‌گرداند.
- اگر اجرای روزانه چند دقیقه دیرتر شود طبیعی است (صف‌بندی زمان‌بند GitHub).
- ریپو عمومی است (برای Actions/Pages رایگان)؛ داده‌ها همه عمومیِ سامانه ستادیران‌اند.
